## **myasus in winre**

---

MyASUS in WinRE (Windows Recovery Environment) is **a diagnostic tool on ASUS computers designed to help troubleshoot hardware issues, even when the operating system isn't running**. It allows you to test various hardware components like hard drives, fans, WiFi, RAM, and displays. \[[1](https://www.asus.com/support/faq/1043576/), [2](https://www.asus.com/content/myasus-in-winre/)\]

**How to access MyASUS in WinRE:**

1. **From the Windows desktop:** If your computer can boot into Windows, you can access WinRE by clicking Start, then Power, then pressing and holding the Shift key while clicking Restart. \[[2](https://www.asus.com/content/myasus-in-winre/), [3](https://www.youtube.com/watch?v=gmWX06VArYo)\]  
2. **From the boot menu:** Turn on your computer and repeatedly press F12 (or F9 for some models) as it starts up to enter the Windows RE (WinRE). \[[3](https://www.youtube.com/watch?v=gmWX06VArYo), [4](https://www.asus.com/support/faq/1047855/)\]  
3. **In WinRE:** Select "Troubleshoot" and then "MyASUS in WinRE". \[[4](https://www.asus.com/support/faq/1047855/)\]

**Features of MyASUS in WinRE: \[[2](https://www.asus.com/content/myasus-in-winre/)\]**

* **System Diagnostics:** This allows you to test various hardware components and identify potential issues. \[[1](https://www.asus.com/support/faq/1043576/), [2](https://www.asus.com/content/myasus-in-winre/)\]  
* **Cloud Recovery:** This feature allows you to restore your computer to its factory default settings from a backup on the cloud. \[[4](https://www.asus.com/support/faq/1047855/), [5](https://www.youtube.com/watch?v=xN7AzT4GjyI&pp=0gcJCdgAo7VqN5tD#:~:text=In%20this%20video%2C%20we%20will%20show%20you,Resources:%20How%20to%20Check%20Model%20and%20BIOS)\]  
* **Factory Reset:** You can use MyASUS in WinRE to perform a factory reset, which restores your computer to its original state. \[[6](https://www.asus.com/support/faq/1041621/), [7](https://www.asus.com/us/support/faq/1041621/#:~:text=ASUS%20Recovery%20allows%20Windows%20pre%2Dinstalled%20to%20be,be%20restored%20back%20to%20the%20one%20pre%2Dinstalled.)\]  
* **Component Testing:** MyASUS in WinRE allows you to test individual components like hard drives, fans, WiFi, RAM, and displays. \[[2](https://www.asus.com/content/myasus-in-winre/), [8](https://www.asus.com/us/support/faq/1043576/)\]

**Troubleshooting Tips:**

* If MyASUS in WinRE is not available, you may need to use the system diagnosis function in MyASUS in UEFI or the MyASUS in RE for USB tool. \[[1](https://www.asus.com/support/faq/1043576/)\]  
* If a component test fails, MyASUS in WinRE will generate a QR code that you can use to access support information. \[[2](https://www.asus.com/content/myasus-in-winre/)\]  
* If you are unable to access WinRE using F9 or F12, you can access the advanced startup options in Windows Settings. \[[6](https://www.asus.com/support/faq/1041621/)\]
