# Transcript: How to Create and Use a Windows Recovery Drive

## Introduction

If your PC encounters issues, such as "Not booting into Windows," this guide will help you create a recovery drive or use a system restore point.

## Create a Recovery Drive

### Step 1: Create a Recovery Drive and Boot to WinRE

1. Search for "Create a recovery drive" in the Windows Search Bar.  
2. Click \[Create a recovery drive\].  
3. Select the checkbox for "Back up system files to the recovery".  
4. Plug in a USB Drive (Make sure to back up your files, as all data on the USB will be deleted).  
5. Select the USB drive and click \[Next\], then \[Create\].  
6. The process will take approximately 2 hours.  
7. Click \[Finish\] once the recovery drive is ready.

### Step 2: Boot from the Recovery Drive

1. Plug in the USB drive.  
2. Press and hold the \[Escape Key\], then press the \[Power Key\] to enter the ASUS boot process.  
3. Select the USB boot device.  
4. The computer will enter Windows Recovery Environment (WinRE).  
5. Choose your language and keyboard layout.

### Step 3: Recover from the System Drive

1. Select \[Recover from a drive\].  
2. Choose the recovery option based on your needs.  
3. Click \[Recover\] to start the process.  
4. Ensure the AC adapter remains plugged in throughout the process.  
5. Do not force shut down to avoid issues.  
6. The computer will restart and enter the Windows basic setup page.  
7. Complete the setup to return to Windows.

## Use a System Restore Point

### Step 1: Restore the System Using a Restore Point

1. Select \[Troubleshoot\], then choose \[System Restore\].  
2. Select your operating system.  
3. Click \[Next\] to begin the process.

### Step 2: Choose a Restore Point

1. Select a restore point that you want to use.  
2. Verify the restore point details and click \[Finish\].  
3. Click \[Yes\] to start the restore process.  
4. Ensure the AC adapter remains connected throughout the process.  
5. Do not force shut down to prevent issues.  
6. The computer will restart and enter Windows.

### Step 3: System Restoration Completed

Congratulations\! The system has been restored to the selected restore point.
