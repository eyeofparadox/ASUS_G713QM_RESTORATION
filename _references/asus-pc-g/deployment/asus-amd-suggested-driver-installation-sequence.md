Note: The driver name may various determined by the different models. So, if you don’t find some drivers in the following list, please ignore it. (If there is the same driver name, please just download the latest version by date.)

Order	Name	Category	Note	Example
1	AMD Graphics and HDMI Driver	Graphics	 	
2	AMD Chipset Driver	Chipset	 	
3	AMD Control Panel	Software and Utility	Access to Microsoft store to download.	
4	nVIDIA Graphic Driver	Graphics	If your computer is with nVIDIA graphics device.	
5	nVIDIA Control Panel	Software and Utility	Access to Microsoft store to download.	
6	Audio Driver	Audio	 	
7	Bluetooth Driver	Bluetooth	 	
8	Wireless LAN Driver	Networking	 	
9	Others	 	All the other drivers can be installed in any order.
