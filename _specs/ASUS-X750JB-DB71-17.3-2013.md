## **ASUS X750JB-DB71 17.3" i7-4700HQ 2.4GHz 16GB 2 x 1TB 5400rpm HDD W8 Laptop Computer**

The ASUS X750JB-DB71 is a 17.3-inch laptop that was released in 2013\. It features an Intel Core i7-4700HQ processor, 16GB of RAM, and dual 1TB hard drives. It also has an NVIDIA GeForce GT 740M graphics card. 

**Here's a breakdown of the specs:**

* Processor: Intel Core i7-4700HQ (2.4GHz base clock, up to 3.4GHz with Turbo Boost)  
* Memory: 16GB DDR3 RAM  
* Storage: 2 x 1TB 5400rpm Hard Disk Drives (HDD)  
* Display: 17.3" HD+ (1600 x 900\) LED-backlit display  
* Graphics: NVIDIA GeForce GT 740M with 2GB DDR3 VRAM  
* Operating System: Windows 8 (64-bit)  
* Optical Drive: SuperMulti DVD burner  
* Networking: 10/100/1000Mbps Gigabit Ethernet, 802.11b/g/n Wi-Fi  
* Other Features: Built-in webcam and microphone, stereo speakers with SonicMaster technology, SD card reader 

**Performance:**

The Intel Core i7-4700HQ is a quad-core processor that offers good performance for everyday tasks and some more demanding applications. The NVIDIA GeForce GT 740M is a dedicated graphics card that can handle some light gaming and multimedia tasks. However, it's not a high-end gaming card, so don't expect to play the latest games at the highest settings. 

**Pros:**

**Cons:**

**Overall:**

The ASUS X750JB-DB71 is a decent all-around laptop that offers a good balance of features and performance.
